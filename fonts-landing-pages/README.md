# Fontes locais dos conceitos

- Manrope: `../portfolio/assets/manrope-400.ttf`, `manrope-500.ttf`, `manrope-700.ttf`; licença `Manrope-OFL.txt`.
- URW Bookman Light: títulos regulares de Dona Benta.
- URW Bookman Demi: títulos pesados de Burger King.
- DejaVu Sans Condensed Bold: títulos de Nescau e Doritos.
- DejaVu Sans Condensed Bold Oblique: títulos inclinados de Doritos.

As licenças acompanham os arquivos. Na implementação, declare `@font-face` com o peso e estilo correspondentes. Copie as fontes necessárias para a página e use caminhos relativos. Não dependa de fontes instaladas no computador do visitante.
